# PostgreSQL Online Bookstore Analysis

## Project Overview
Designed and analyzed an Online Bookstore database using PostgreSQL.

## Database Tables
- Books
- Customers
- Orders

## Skills Used
- SQL Joins
- Aggregations
- GROUP BY
- HAVING
- ORDER BY
- Data Analysis

## Key Business Questions Solved
1. Most expensive book
2. Total revenue generated
3. Most frequently ordered book
4. Top customers by spending
5. Total books sold by genre
6. Remaining stock after orders

## Files Included
- schema.sql
- queries.sql
- Books.csv
- Customers.csv
- Orders.csv

## Tools Used
PostgreSQL
